# Rauli Rantanen – meri-CV

Staattinen verkko-CV, joka julkaistaan GitHub Pagesiin (`.github/workflows/pages.yml`) jokaisesta `main`-haaran pushista.

- `index.html` – koko sivu
- `assets/` – kuvat
- `liitteet/` – ladattavat tiedostot (lisätään myöhemmin)

Hakasulkeissa `[näin]` olevat kohdat odottavat Raulin omia tietoja.
